# LOVE GAME — версия с настоящим управлением

## Что уже есть
- персонаж, которым можно управлять пальцем через виртуальный джойстик;
- работает также с клавиатурой WASD / стрелками на компьютере;
- большая милая локация с тропинками;
- 12 сердечек нужно реально собрать;
- 3 котика двигаются по карте и могут преследовать персонажа;
- после 3 столкновений игра начинается заново;
- после сбора всех сердечек открывается коробочка и затем письмо;
- все изображения лежат отдельно в папке `assets`.

## Куда положить картинки

Папка:
`assets/`

Файлы:
1. `player.png` — персонаж девушки, PNG с прозрачным фоном, желательно 256x256.
2. `cat1.png` — первый котик, PNG с прозрачным фоном, 256x256.
3. `cat2.png` — второй котик.
4. `cat3.png` — третий котик.
5. `heart.png` — одно сердечко, PNG с прозрачным фоном, 128x128.
6. `box.png` — розовая/кремовая подарочная коробочка, PNG с прозрачным фоном, 256x256.

Важно: имена должны совпадать БУКВАЛЬНО.

## Как запускать
Просто открой `index.html` в браузере.

Для iPhone лучше потом разместить папку на хостинге (например GitHub Pages / Netlify), чтобы открыть игру обычной ссылкой.

## Если хочешь нарисовать ассеты
Лучше сделать все картинки в одном стиле: мягкая 2D-иллюстрация, пастельные цвета, толстый аккуратный контур, прозрачный фон.
